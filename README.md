# Robot Simulation Environment

## Introduction
This robot simulation environment is designed to allow users to test and visualize the behavior of a robotic system within a simulated 2D field. The simulator includes functionalities such as running predefined commands like moving in a straight line, turning around, and waiting for specified durations.

## Installation

### Requirements
Before running the simulator, you will need to have Python installed along with the `pygame` and `pygame_gui` libraries, which are used for creating the graphical user interface and rendering the simulation.

### Python Installation
If you do not have Python installed, download it from [python.org](https://www.python.org/downloads/) and follow the installation instructions for your operating system.

### Required Libraries
Once Python is installed, you can install the required libraries using `pip`. Run the following command in your terminal:

```bash
pip install pygame pygame_gui
```
